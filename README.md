# 🌐 Personal Portfolio Website

A modern, responsive, and visually appealing personal portfolio website built using **HTML5, CSS3, and JavaScript**. This project showcases my skills, education, projects, and contact information through a clean and interactive user interface.

---

## 📌 Features

- ✨ Modern UI with glassmorphism design
- 📱 Fully Responsive Layout
- 🎨 Smooth animations and transitions
- 📑 Sticky Navigation Bar
- 🍔 Animated Mobile Sidebar Menu
- 🔗 Active Navigation Highlight on Scroll
- 👨‍💻 About Me Section
- 🎓 Education Timeline
- 💡 Technical & Professional Skills
- 📂 Project Showcase
- 📞 Contact Section with Contact Form
- ⚡ Smooth Scrolling Experience

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
- Google Fonts (Poppins)
